# 电视上怎么看（APTV 订阅接入）

给完全不想碰命令行的人看的版本。原理只有一句：
**电脑上开一个小网页服务，把生成的频道表放在家里网段里，Apple TV 用这个地址去取。**
整个过程不出互联网，不做端口映射，关掉窗口就停了。

---

## 三步

**第 1 步：双击项目根目录的 `启动电视订阅服务.bat`**

窗口里会出现这样的内容：

```
==============================================================
  APTV 局域网订阅服务
==============================================================
  http://192.168.1.4:8787/hunan.m3u   # 湖南本地优先（39 个台）
  http://192.168.1.4:8787/aptv.m3u    # 全量（央视 + 卫视 + 湖南）

  防火墙状态：已关闭，不会拦电视
==============================================================
```

**这个窗口不能关**，关了电视就订阅不上。以后每次看电视前都要先双击它一次
（除非已经把服务搬到 NAS 上常驻，那是 P4 的事）。

**第 2 步：先用手机确认网络是通的**

手机连家里 Wi-Fi（必须是电视用的同一个 Wi-Fi），Safari 打开
`http://192.168.1.4:8787/`

看到「✅ 服务已经起来了」这个页面，才继续往下做。这一步是分水岭，
能一下子把问题分成「网络不通」和「App 不接受」两类。

**第 3 步：APTV 里添加订阅**

APTV → 添加订阅 / 播放列表 → 输入网址，填：

```
http://192.168.1.4:8787/hunan.m3u
```

要央视 + 卫视 + 湖南全都在一个列表里，就填 `.../aptv.m3u`。
名字随便起（建议写「家里湖南」），保存后等它自己拉取，成功后会出分组：
📍 湖南本地 / 长沙 / 市州 / 金鹰 等。

---

## 加不上时按这个顺序查

| 现象 | 说明什么 | 怎么处理 |
| --- | --- | --- |
| 手机打开 `http://192.168.1.4:8787/` 也转圈/拒绝连接 | 电脑根本连不上，跟 APTV 无关 | 看下一条 |
| 手机能打开，Apple TV 打不开 | 电视和电脑不在同一网段，或路由器开了「无线隔离 / 访客网络」 | 见下面「网段」一节 |
| 服务窗口里**一行都没跳出来** | 请求根本没到电脑，100% 是网络层问题 | 同上，别再改 APTV |
| 窗口里跳出了 `★ 有别的设备连上来了：192.168.1.x` 但 APTV 还是报错 | 网络通了，问题在 APTV 输入或 tvOS 侧 | 核对网址是否完整、有没有多空格/换行；先试 `aptv.m3u`；删掉旧订阅重加 |
| 订阅成功但所有台都播不出来 | 流地址要在**看电视的那个网络**里才可播 | 家里是联通宽带，优先试湖南卫视/经视这类走 `58.20.64.92:9999` 的台；移动源那些台在联通宽带下能不能播，只有真机知道 |

### 网段怎么对

Apple TV：**设置 → 网络 → （当前网络）→ 看 IP 地址**。
电脑：**192.168.1.4**。
两边前三段必须一样（都是 `192.168.1.x`）。

- 电视是 `192.168.1.x` → 填 `http://192.168.1.4:8787/hunan.m3u`
- 电视是别的段（例如 `192.168.31.x`、`192.168.100.x`）→ 说明电视连的是另一个 Wi-Fi
  或访客网络。让电视去连电脑所在的那个 Wi-Fi，或者在路由器里关掉「无线隔离 /
  AP Isolation / 访客网络隔离」。这种情况下填 `192.168.1.4` 永远不会成功。

### 还是不行：把日志给我

服务窗口里的每一行都同时写进了 `data/logs/requests.log`。
重试一次 APTV 添加订阅，然后把这个文件发我看，能直接判断请求到没到电脑。
